# HTML

## Разметка

Страницы в браузере создаются в файлах `index.html`. Это каркас, костяк, "рыба" страницы. Там пишут теги, показываю браузеру, где и как отображать данные.

## Хоткеи

Горячие клавиши. Например, при создании страницы `index.html` в Visual Studio Code можно ввести `!`, нажать `TAB` и получить шаблон html-документа.

В Visual Studio Code при сочетании клавиш `CTRL+S` можно быстро сохранять документ и делать стандартное форматирование, чтобы строки встали на свои места.

Можно нажать `u` потом `TAB` и VSC допишет этот тег.

При быстрой разработке html-страниц часто вставляют "текст-рыбу". Пишется слово `lorem`, можно дописать значение (например 42 слова) и нажать `TAB` - VSC написат текст из нужного количество слов.

Можно быстро дублировать строку в VSC, для этого нажать `CTRL+ALT+стрелка вниз`.

## Теги 

Шаблонный `index.html` документ состоит из тегов: DOCTYPE (#1), html (#2), head (#3), body (#4). Они имеют свою вложенность, "голова" и "тело" вкладываются в `html`.

Само тело страницы пишется в тег `body`. Например, создание страницы-резюме может начинаться с тега `h1` (#5) - заголовок первого уровня (большой текст). Теги оборачиваются в угловые скобки: '<>'. Дополнительно можно создавать заголовки разных размеров от `1` до `6` (#6-10).

Часто используется тег параграфа - `p` (#11).

Выделить текст "жирным" - `b` (#12).

Выделить текст "курсивом" - `i` (#13).

Подчеркнуть текст - `u` (#14).

Создать таблицу - `table` (#15). Внутри строки - `tr` (#16), ячейки - `td` (#17).

Нумерованный список - `ol` (#18).

Ненумерованный список - `ul` (#19).

Пункт списка - `li` (#20).

## Списки 
Список можно сделать нумерованным и без номеров. Списки состоят из пунктов.

## Таблицы
В html можно рисовать таблицы. Для этого используется тег `table`. Внутри пишется `tr` для строк и `td` для ячеек. У `table` могут быть атрибуты, например: `<table border="1">` (границы таблицы).



# CSS

## Подключение

В VSC стили подключаются через `link->TAB`: `<link rel="stylesheet" href="./styles.css">`.

## Селектор, свойство, значение

Для изменения свойств элементов страницы используются селекторы. Например, чтобы поменять фон страницы применяется селектор - body. Значением свойства (background-color) будет цвет - lime.

```css
body {
  background-color: lime;
}
```

## Класс, идентификатор

В html элементу можно задать идентификатор или класс, и обращаться к ним через селектор класса или селектор идентификатора. Например, на странице есть блок `.box`. Для обращения к селектору класса используется "точка", а к идентификатору - "решётка". Идентификатор на странице должен быть лишь один. Приоритет при применении стилей у идентификатора выше, чем у класса (специфичность).

```css
.box {}
#box-new {}
```

## Границы

Блокам можно рисовать границы через свойство border.

```css
border: 2px solid lightseagreen;
```

### Закругление границ

```css
border-radius: 8px;
```

## Отступы

Могут быть внешние и внутренние отступы.

```css
padding: 0.42em;
margin: 0.42em 0;
```

## Псевдоклассы

### Чередование для блоков с классом

На странице может быть несколько блоков с информацией и их удобно чередовать по стилям через псевдокласс `:nth-child(even)` или `:nth-child(2n)`.

```css
.box:nth-child(2n) {}
```

### Эффект при наведении мышки

При наведении мышки можно применять особые стили через псевдокласс `:hover`.

```css
.box:hover {
  color: whitesmoke;
}
```

## Шрифты

### Выравнивание по центру

```css
text-align: center;
```

### Удаление подчёркивания у ссылок

```css
text-decoration: none;
```

## Flexbox

Flexible Box Layout. Гибкий одномерный макет. Одна ось - или горизонталь или вертикаль. Используется для выравнивания элементов в строке/столбце. Для включения элементу-родителю присваивается свойство `display: flex;`. После этого все прямые потомки становятся flex-элементами.

### Направление оси

Может быть: row, row-reverse, column, column-reverse.

```css
flex-direction: row;
```

### Выравнивание по главной оси

Может быть: flex-start, flex-end, center, space-between, space-around, space-evenly.

```css
justify-content: flex-start;
```

### Выравнивание по поперечной оси

Возможные значения: stretch, flex-start, flex-end, center, baseline.

```css
align-items: stretch;
```

### Отступы между элементами

Удобное свойство при котором не надо детям задавать margin. Возможные свойства: gap, column-gap, row-gap.

```css
gap: 16px;
```

### Перенос на новую строку

Обычно элементы умещаются в одну строку. Возможные значения: nowrap, wrap, wrap-reverse.

```css
flex-wrap: nowrap;
```

Часто используют сокращённо. То же, что flex-direction + flex-wrap.

```css
flex-flow: row wrap;
```

## Grid

Двумерные макеты. На родителе задать: `display: grid;`, потомки станут grid-элементами.

### Ширина колонок

```css
grid-template-columns: 200px 1fr 1fr;
```

### Высота колонок

```css
grid-template-rows: 100px auto 1fr;
```

### Отступы между ячейками

```css
gap: 16px;
```

fr - доля свободного места

1fr - оставшееся место

repeat() - чтобы не писать много раз

minmax() - гибкая ширина

### Размещение элементов

#### По линиям

У сетки есть линии (номера). Элемент можно "натянуть" между ними.

```css
.item {
  grid-column: 1 / 3;   /* от линии 1 до линии 3 (занимает 2 колонки) */
  grid-row: 2 / 4;      /* от линии 2 до линии 4 (занимает 2 строки) */
}
```

Можно использовать span, чтобы указать количество ячеек.

```css
.item {
  grid-column: span 2;  /* занимает 2 колонки */
}
```

#### По областям

Самый наглядный способ для макетов типа «шапка, контент, сайдбар, подвал».

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
```

Grid отличается от Flex тем, что Flex - это одномерный макет (либо строки, либо столбцы), а Grid - это двумерный макет (сразу и строки и столбцы). Flex подходит для выравнивания элементов внутри строки. Grid больше подходит для структуры всей страницы, для сложной сетки. Их часто используют вместе - Grid для общего каркаса страницы, Flex для выравнивания контента внутри ячеек.

  grid-template-rows: 20% 20% 20% 20% 20%;
}

#water {
  grid-column-start: 3;
}
