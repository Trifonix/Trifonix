# HTML

## Разметка

Страницы в браузере создаются в файлах `index.html`. Это каркас, костяк, "рыба" страницы. Там пишут теги, показываю браузеру, где и как отображать данные.

## Хоткеи

Горячие клавиши. Например, при создании страницы `index.html` в Visual Studio Code можно ввести `!`, нажать `TAB` и получить шаблон html-документа.

В Visual Studio Code при сочетании клавиш `CTRL+S` можно быстро сохранять документ и делать стандартное форматирование, чтобы строки встали на свои места.

Можно нажать `u` потом `TAB` и VSC допишет этот тег.

При быстрой разработке html-страниц часто вставляют "текст-рыбу". Пишется слово `lorem`, можно дописать значение (например 42 слова) и нажать `TAB` - VSC написат текст из нужного количество слов.

Можно быстро дублировать строку в VSC, для этого нажать `CTRL+ALT+стрелка вниз`.

## Теги 

Шаблонный `index.html` документ состоит из тегов: DOCTYPE (#1), html (#2), head (#3), body (#4). Они имеют свою вложенность, "голова" и "тело" вкладываются в `html`.

Само тело страницы пишется в тег `body`. Например, создание страницы-резюме может начинаться с тега `h1` (#5) - заголовок первого уровня (большой текст). Теги оборачиваются в угловые скобки: '<>'. Дополнительно можно создавать заголовки разных размеров от `1` до `6` (#6-10).

Часто используется тег параграфа - `p` (#11).

Выделить текст "жирным" - `b` (#12).

Выделить текст "курсивом" - `i` (#13).

Подчеркнуть текст - `u` (#14).

Создать таблицу - `table` (#15). Внутри строки - `tr` (#16), ячейки - `td` (#17).

Нумерованный список - `ol` (#18).

Ненумерованный список - `ul` (#19).

Пункт списка - `li` (#20).

## Списки 
Список можно сделать нумерованным и без номеров. Списки состоят из пунктов.

## Таблицы
В html можно рисовать таблицы. Для этого используется тег `table`. Внутри пишется `tr` для строк и `td` для ячеек. У `table` могут быть атрибуты, например: `<table border="1">` (границы таблицы).
